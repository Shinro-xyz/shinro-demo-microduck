# Third-party licence texts

Texts for material **redistributed in this repository** by third parties. The
components and their provenance are listed in `NOTICE` at the repository root.

## `pollen-microduck/`

The Apache License, Version 2.0 text under which Pollen Robotics publishes the
Microduck MJCF, mesh set and walking policy. These are redistributed here
verbatim (see `NOTICE` §3), so their licence travels with them.

The text is the unmodified Apache License 2.0 — the same standard text as this
repository's own `LICENSE`. It is reproduced here under its own directory
because Apache-2.0 §4 requires the notice to be retained with the redistributed
material, and because the two grants are from different parties: this
repository's `LICENSE` is Shinro SAS's grant over *this* repository's code,
while this one is Pollen Robotics' grant over *their* robot assets.

Pollen Robotics should not be contacted about anything in this repository other
than their own assets.
